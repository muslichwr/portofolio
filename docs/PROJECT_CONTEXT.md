## 5. Core Narrative & Positioning

The portfolio bridges the gap between **industry-standard software engineering practices** and **secondary vocational school (SMK) learning reality**:
- **Teaching Philosophy:** *"Logic First, Syntax Later"* — prioritizes architectural mental models and troubleshooting logic before rote memorization of command syntax or code snippets.
- **Role Model & Visi:** An empathetic, reflective, and facilitative educator who uses real errors (*"Error of the Day"*, logs, triage) as primary learning vehicles rather than obstacles.
- **Growth Mindset:** Treats pedagogical shortcomings (e.g., lab time management, dense instructional pacing) as empirical data for iterative cycle refinement.

---

## 6. Core Principles & Guardrails

### Academic Evidence Takes Precedence Over Presentation
1. **No Fabricated Evidence:** The portfolio must never fabricate teaching experiences, student responses, artifacts, scores, grades, theories, citations, or professional background simply to achieve a higher score.
2. **Honest Rubric Alignment:** Meeting rubric criteria means mapping and organizing **verifiable, authentic evidence**. Where evidence is incomplete or unverified, it must be acknowledged transparently rather than obscured with invented claims.
3. **Truthful Reflection:** Authentic reflection preserves real-world friction — lab network constraints, syntax typos, OS packaging differences (Ubuntu 20.04 vs 22.04), time management limits, and partial syllabus completion.

---

## 7. Success Criteria

1. **Complete Rubric Coverage:** Full, transparent mapping of all required UTS PPL Terbimbing and PPG Prajabatan portfolio criteria backed by authentic downloadable artifacts (Google Drive links to official PDFs).
2. **Factual & Academic Consistency:** Absolute consistency across all pages regarding identity, educational degrees, teaching cycles, assessment scores, and verified academic references.
3. **High-Performance Architecture:** Fast, accessible, accessible-first React Server Component architecture using Next.js App Router and a restrained monochrome design system.

---

## 8. Non-Goals & Boundaries

- **Not a Generic Resume:** This is not a superficial CV landing page; academic depth and pedagogical reflection are central.
- **Not a Live LMS / CBT Platform:** The portfolio does not run student exam sessions or host classroom management logic; it showcases and analyzes instructional designs.
- **No Decorative Over-Engineering:** Design elements (animations, gradients, colors) must serve clarity and readability, never overshadowing academic content.
- **No Hallucinated Citations:** Theories and authors must never be invented or superficially pasted to look scholarly.
